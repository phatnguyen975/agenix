# Web Interface Guidelines

Review the selected UI implementation against applicable interface guidance.

1. Read the bundled [Web Interface Guidelines](references/web-interface-guidelines.md).
2. Inspect the files or surface in scope. Ask for the review scope when it is missing.
3. Apply the relevant rules. Distinguish source observations from behaviors that require browser or human verification.
4. Report actionable findings with file and line. Use the caller's output format when provided.
